## 💡 核心结论速览

### 题型分布
- **综合分析**: 28%（每年5-6题）→ 最后大题，必考
- **增长相关**: 21%（每年4-5题）→ 核心计算题型
- **分数相关**: 20%（每年3-5题）→ 比重、平均数、基础题
- **其他**: 26%（每年5-7题）→ 简单计算，送分题

### 必背公式TOP5
```
1. 增长率 r = 现期/基期 - 1
2. 基期 = 现期/(1+r)
3. 比重 = 部分/整体
4. 平均数 = 总量/个数
5. 间隔增长率 = r1 + r2 + r1×r2
```

### 必掌握技巧TOP3
1. **截位直除法**: 所有除法计算必用（使用率80%+）
2. **两期比重比较口诀**: 部分快比重涨，部分慢比重降
3. **综合分析排除法**: 先做判断题，做出3个选项即锁定答案

### 常见陷阱TOP3
1. ❌ 偷换时间（2023年说成2024年）
2. ❌ 混淆增长率与增长量（率是%，量是具体数值）
3. ❌ 单位不统一（万元、亿元混算）

## 🚀 备考建议

### 时间分配
- **资料分析在行测中的位置**: 第116-135题（最后20题）
- **建议用时**: 25-30分钟（占行测总时间20-25%）
- **正确率目标**: 85%+（17题以上）

### 刷题策略
- **基础阶段**: 不限时，重准确率（正确率90%+）
- **提高阶段**: 每组限时10分钟（5题）
- **冲刺阶段**: 4组限时30分钟（20题）

### 错题整理
- 按题型分类整理错题
- 总结个人易错点（如易忘减1、易混单位）
- 考前反复看错题本
