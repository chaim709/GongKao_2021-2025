## 🎯 五、2026年备考建议

### 5.1 时间分配建议

**考场作战方案**（资料分析20题，建议用时25-30分钟）:

```
前10题（基础计算）:  每题1.5分钟  = 15分钟
中5题（中等难度）:   每题2分钟    = 10分钟  
综合分析（5题）:     共5-6分钟    = 6分钟
                               总计: 31分钟
```

**策略**:
- 前15题正确率必须达到90%+（送分题）
- 综合分析每题控制在1分钟内（做3个选项即可）
- 超时1分钟仍未解出 → 立即跳过

### 5.2 核心公式必背清单

**增长相关**（必考）:
```
增长率 r = (现期-基期)/基期 = 现期/基期 - 1
基期 = 现期/(1+r)
增长量 = 现期 - 基期 = 基期×r/(1+r)
间隔增长率 = r1 + r2 + r1×r2
```

**分数相关**（必考）:
```
比重 = 部分/整体
平均数 = 总量/个数
倍数 = A/B
```

**比重比较口诀**（秒杀技）:
```
部分增速 > 整体增速 → 比重上升
部分增速 < 整体增速 → 比重下降
```

### 5.3 必练题型清单

**第一优先级**（每天必练）:
- [ ] 综合分析题（每天5题，练习排除法）
- [ ] 增长率计算（每天3题，练截位直除）

**第二优先级**（隔天练）:
- [ ] 比重计算（每次5题）
- [ ] 平均数问题（每次3题）

**第三优先级**（每周练）:
- [ ] 间隔增长率（每周2题）
- [ ] 基期计算（每周3题）

### 5.4 避坑清单

**考场常见失误TOP5**:
1. ❌ 增长率忘记减1 → ✅ 记住 r = 现期/基期 - 1
2. ❌ 偷换时间（2023说成2024）→ ✅ 做题前先圈出时间
3. ❌ 单位不统一（万元vs元）→ ✅ 计算前先统一单位
4. ❌ 综合分析4个选项都算 → ✅ 做出3个即锁定答案
5. ❌ 百分点当成百分数 → ✅ 百分点=两个%相减

## 💡 六、命题组思路解析

### 6.1 江苏卷特色

**与国考的差异**:
- 综合分析题占比更大（28% vs 国考20%）
- 计算精度要求更高（通常需要3位截位）
- 材料综合性更强（文字+表格+图形组合）

**命题规律**:
- 每年必有1-2题"陷阱题"（偷换概念/时间）
- 最后一组材料难度最高（综合材料+复杂计算）
- 间隔增长、年均增长等"高级题型"穿插出现

### 6.2 能力考察重点

**核心能力**（占80%分值）:
1. 数据定位能力（快速找到相关数据）
2. 公式应用能力（熟练套用公式）
3. 估算计算能力（截位直除、特征数字）

**辅助能力**（占20%分值）:
4. 综合判断能力（排除错误选项）
5. 细心程度（避免偷换概念陷阱）
