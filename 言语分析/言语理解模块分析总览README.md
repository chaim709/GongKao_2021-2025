```
Step 3: 排除选项（20秒）
└─ 排除片面、无关、过度引申
```

### 四、常见陷阱

#### 逻辑填空陷阱Top 5
1. **成语望文生义**："不刊之论"≠不能刊登
2. **忽视语境**：只看词义，不看上下文
3. **忽视搭配**："增强观念"✗ → "增强意识"✓
4. **感情色彩错误**：消极语境用褒义词
5. **程度不当**：程度过轻或过重

#### 主旨概括陷阱Top 5
1. **片面概括**：只提到分论点
2. **过度引申**：超出原文范围
3. **偷换概念**：主题词不一致
4. **无中生有**：原文未提及
5. **本末倒置**：把背景当主旨
