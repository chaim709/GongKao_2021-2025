**⚡ 法律题核心秘诀**:

## ⚡ 三、万能解题技巧

### 3.1 排除法（适用所有题型）

**使用步骤**:
1. **第一轮排除** - 绝对化表述（所有、唯一、最、必须等）
2. **第二轮排除** - 明显常识错误（时间错误、概念错误等）
3. **第三轮排除** - 不符合题干要求的选项
4. **最后选择** - 剩余选项中选最符合原文/法条/原理的

**适用率**: 100%（每道题都可用）

### 3.2 组合选择题专用技巧

**题型识别**: 题干有（1）（2）（3）（4），选项是A（1）（2）、B（1）（3）等

**解题步骤**:
1. 逐个判断每个小项的正误
2. 根据判断结果锁定答案
   - 如果判断出（1）对（2）错（3）对（4）不确定 → 在含（1）（3）的选项中选
3. 不需要全部判断完，判断出2-3个即可锁定答案

**时间节省**: 比逐项全判断节省30-50%时间

## 🎯 四、考场实战流程

**标准答题流程**（每题30-40秒）:

```
1. 读题干（5秒）→ 识别学科（时政?法律?科技?）
2. 抓关键词（3秒）→ 激活对应技巧
3. 快速排除（10秒）→ 排除2个明显错误选项
4. 精准选择（10秒）→ 在剩余选项中选最符合的
5. 涂卡/确认（2秒）
```

**遇到难题策略**:
- 超过40秒未解出 → 立即跳过
- 完全不会的题 → 用排除法猜一个，不空题
- 纠结两个选项 → 选更符合原文/法条的那个，不纠结
