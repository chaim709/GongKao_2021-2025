## 💡 重要发现

### 江苏卷三大特色
1. **排列组合绝对主导**：44%占比，每年约9题，远超国考和其他省份
2. **多级数列是特色**：22%占比，江苏独有高频考点
3. **应用题占比低**：工程+行程+经济仅11%，不必花太多时间

### 5年趋势分析
- ↗️ **容斥原理**：2023年后频率上升，成为新增高频考点
- ➡️ **排列组合**：稳定高频，每年7-9题
- ➡️ **数列**：平稳出现，每年4-6题

### 2026年预测
1. 排列组合：8-9题（必考）
2. 数列：5-6题（其中多级数列4题）
3. 容斥原理：1-2题（新趋势）
4. 应用题：2-3题（工程/行程/几何各1题左右）

## 🚀 备考建议

### 时间分配原则
- **排列组合**：40%时间（最重要，占比44%）
- **数列**：30%时间（较简单，占比30%）
- **应用题**：20%时间（占比低，性价比一般）
- **其他**：10%时间（容斥、几何等）

### 三阶段学习计划

**第一阶段（1-2周）- 基础巩固**
- 目标：熟练掌握基本公式和方法
- 重点：数列（等差等比公式）+ 排列组合（A_n^m、C_n^m公式）
- 每日：做题10题，总结错题

**第二阶段（2-3周）- 技巧提升**
- 目标：掌握高级技巧，提升难题正确率
- 重点：排列组合（捆绑法、插空法、隔板法）+ 多级数列（逐级做差）
- 每日：做题15题，熟练运用技巧映射表

**第三阶段（1周）- 真题模拟**
- 目标：控制时间，模拟考场
- 方法：20题/15分钟，严格计时
- 重点：使用解题模板库，快速识别题型

## 📖 数据字段说明

### JSON增强字段
每道题新增以下4个专业分析字段：

1. **题型识别**：一眼看出是什么题型（如"数列-多级数列"）
2. **考察内容**：理解命题人想考什么能力（如"逐级分析能力"）
3. **思维方式**：掌握最优解题思路（如"逐级做差法"）
4. **解题方法**：明确用什么方法（如"多级数列法"）
