### 新增字段说明

#### 1. 题型识别
**格式**: 一级分类-二级分类-三级分类
**示例**: `增长相关-增长率-年均增长率计算`

#### 2. 考察内容
包含:
- 考察的公式/概念
- 核心能力要求
- 江苏特色/陷阱
- 300字专业描述

#### 3. 思维方式
**格式**: 5-7步详细解题流程
**示例**: ①判断→②计算n→③计算倍数→④代入验证→⑤选答案

#### 4. 解题方法
**结构化呈现**:
- 【核心技巧】: 最重要的方法
- 【公式】: 相关公式
- 【江苏特色】: 特殊规则
- 【辅助】: 辅助方法

## 🎯 江苏省考5大特色

1. **年均增长率**: 江苏/全国/五年规划需前推基期1年
   - 如2015-2019年，n=5，基期=2014年

2. **百化分法高频**: 需熟记1/7~1/20的转换
   - 7.7%=1/13, 14.3%=1/7, 20%=1/5

3. **两期比重送分题**: 差值<|a-b|，选项中选最小的
   - a>b则比重上升，a<b则比重下降

4. **陷阱密集**:
   - 时间陷阱: 累计vs当月
   - 单位陷阱: 亿vs万
   - 概念陷阱: 增长倍vs是几倍
   - 范围陷阱: 苏南vs江苏

5. **技巧>硬算**: 综合分析侧重陷阱识别而非复杂计算
   - 先易后难、口诀秒杀、遇难则跳

## 📖 使用方法

### 刷题阶段
1. 打开JSON文件，对照三级分类针对性练习薄弱题型
2. 每道题都参考"思维方式"，形成标准解题流程
3. 重点关注"考察内容"中的江苏特色和陷阱

### 考前冲刺
1. 熟记"解题方法"中的核心技巧和公式
2. 重点复习江苏5大特色
3. 练习综合分析题的"先易后难"策略

### 查漏补缺
1. 按三级分类统计错题分布
2. 针对高频错误题型，重点研究"考察内容"
3. 对比标准"思维方式"与自己的解题思路
