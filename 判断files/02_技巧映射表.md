## 一、定义判断

### 核心技巧映射

| 题型 | 识别特征 | 解题技巧 | 触发条件 | 时间建议 |
|------|---------|---------|---------|---------|
| 单定义判断 | "符合上述定义的是""属于XX的是" | 关键词法：圈主体、对象、条件 | 题干只有1个定义 | 40-50秒/题 |
| 多定义判断 | "属于XX的是"，题干有2-3个定义 | 对号入座法：先区分定义差异 | 题干有多个定义 | 60-70秒/题 |

### 解题步骤模板

```
【定义判断通用流程】
第一步：快速阅读定义，圈画关键词
  - 主体：谁（人/组织/事物）
  - 对象：对谁/什么
  - 条件：在什么情况下、通过什么方式
  - 结果：达到什么目的/产生什么效果

第二步：对比选项，逐项排除
  - 优先排除主体不符的
  - 再排除对象不符的
  - 最后看条件和结果

第三步：选择完全符合的项
  - 注意"偷换概念"陷阱
  - 警惕"部分符合"的迷惑项
```

### 高频陷阱

| 陷阱类型 | 表现形式 | 应对策略 |
|---------|---------|---------|
| 偷换主体 | 定义说"企业"，选项说"个人" | 严格对照主体资格 |
| 偷换对象 | 定义说"消费者"，选项说"员工" | 明确作用对象 |
| 条件缺失 | 定义要求"自愿"，选项是"强制" | 检查必要条件是否齐全 |
| 范围扩大 | 定义说"故意"，选项包含"过失" | 注意限定词的范围 |

## 二、类比推理

### 核心技巧映射

| 题型 | 识别特征 | 解题技巧 | 触发条件 | 时间建议 |
|------|---------|---------|---------|---------|
| 两词关系 | "A：B" | 关系分类法：确定功能/目的/属性关系 | 题干1个冒号 | 25-30秒/题 |
| 三词关系 | "A：B：C" | 多重关系对比：可能涉及2种以上关系 | 题干2个冒号 | 30-35秒/题 |
| 填空式 | "( )之于A，如同B之于( )" | 类比填空：分析已知词关系推测未知 | 题干有空格或"之于" | 35-40秒/题 |
| 成语关系 | 题干和选项都是成语 | 结构+含义：分析成语内部结构和整体含义 | 都是四字成语 | 30-35秒/题 |

### 关系优先级（江苏卷特点）

```
逻辑关系（优先） > 言语关系 > 常识关系

1. 逻辑关系（必考）：
   - 外延关系：种属、组成、并列（全同/矛盾/反对）、交叉
   - 内涵关系：对应（功能/职业/因果/象征）、属性

2. 言语关系（常考）：
   - 近义、反义、比喻、象征

3. 常识关系（辅助）：
   - 时间、地点、材料、工艺
```

### 解题步骤模板

```
【类比推理通用流程】
第一步：确定题干关系
  - 优先考虑逻辑关系
  - 注意词项顺序（A→B 的关系方向）

第二步：逐项对比选项
  - 排除关系类型不同的
  - 排除关系方向相反的

第三步：选择最优项
  - 若多项关系相同，选择关系最紧密的
  - 注意江苏卷倾向：逻辑关系>言语关系
```

### 高频陷阱

| 陷阱类型 | 表现形式 | 应对策略 |
|---------|---------|---------|
| 关系方向颠倒 | 题干"A用于B"，选项"B用于A" | 严格检查关系方向 |
| 关系类型混淆 | 题干是"功能关系"，选项是"包含关系" | 明确关系本质 |
| 多重关系干扰 | 看到表面关系就选，忽略更本质关系 | 深入分析，找最核心关系 |

## 三、图形推理

### 核心技巧映射

| 题型 | 识别特征 | 解题技巧 | 触发条件 | 时间建议 |
|------|---------|---------|---------|---------|
| 立体拼合 | 给定若干平面图形，问能拼成什么 | 特殊线条法：找最长边、唯一角 | 题干要求"拼合" | 45-60秒/题 |
| 空间重构（折纸盒） | 展开图折成立方体 | 公共边法+相对位置法 | 六面体展开图 | 50-70秒/题 |
| 截面图 | 立体图形被截后的截面 | 截面方向法：判断切割方向 | 问"截面形状" | 40-50秒/题 |
| 数量类-面 | 图形面数有规律 | 数封闭区域 | 图形有明显封闭区域 | 30-40秒/题 |
| 数量类-线 | 图形线条数有规律 | 数线条（一笔画、直线数） | 图形线条特征明显 | 30-40秒/题 |
| 数量类-元素 | 图形元素/部分数有规律 | 数独立部分 | 图形有多个独立部分 | 30-40秒/题 |
| 属性类-对称 | 图形对称性有规律 | 判断轴对称、中心对称 | 图形对称特征明显 | 25-35秒/题 |
| 位置类-动态 | 图形位置变化 | 观察平移、旋转规律 | 相同元素位置变化 | 30-40秒/题 |
| 样式类-叠加 | 图形叠加规律 | 找加减同异运算 | 图形样式可叠加 | 35-45秒/题 |

### 解题思维流程（江苏卷特色）

```
【图形推理万能思路】
看到题目→先观察30秒→按以下顺序思考：

1. 立体图形？
   → 是 → 空间重构（找相对位置）/立体拼合（找特殊线）
   → 否 → 继续第2步

2. 图形有特殊属性？（江苏高频）
   → 对称性（轴对称/中心对称）
   → 曲直性（全曲线/全直线/曲直混合）
   → 封闭性（全封闭/全开放）
   → 是 → 找属性规律
   → 否 → 继续第3步

3. 相同元素在变化？
   → 是 → 位置类（平移/旋转/翻转）
   → 否 → 继续第4步

4. 图形可以叠加？
   → 是 → 样式类（加减同异）
   → 否 → 继续第5步

5. 数数量！
   → 优先数：面（封闭区域）> 线 > 点 > 角 > 元素
   → 找递增、递减、恒定、周期规律

6. 仍不确定？
   → 考虑功能信息（江苏特色：人物动作、物品功能）
```

### 高频陷阱

| 陷阱类型 | 表现形式 | 应对策略 |
|---------|---------|---------|
| 空间重构-相对位置错误 | 相邻面位置对，但相对面错误 | 用"公共边法"验证 |
| 立体拼合-无法拼合 | 看似能拼，实际角度不对 | 用"特殊角"验证 |
| 数量类-数错对象 | 题目考面数，却数了线条数 | 先看选项差异确定数什么 |
| 属性类-混合属性 | 有对称也有非对称，规律不明显 | 看"全部/部分"的比例规律 |

## 四、逻辑判断

### 核心技巧映射

| 题型 | 识别特征 | 解题技巧 | 触发条件 | 时间建议 |
|------|---------|---------|---------|---------|
| 翻译推理 | "如果...那么""只有...才" | 公式推理法：翻译+逆否等价 | 题干有充分必要条件 | 50-70秒/题 |
| 分析推理 | 多个条件，问排列/组合/匹配 | 排除法+假设法 | 题干有多个约束条件 | 70-120秒/题 |
| 加强论证 | "最能加强/支持上述论点" | 论证分析法：搭桥/补充论据 | 问"加强" | 50-70秒/题 |
| 削弱论证 | "最能削弱/质疑上述论点" | 论证分析法：断桥/否定论据 | 问"削弱" | 50-70秒/题 |
| 原因解释 | 题干有矛盾现象，问"解释" | 因果分析法：找能消除矛盾的原因 | 有悖论/矛盾现象 | 50-60秒/题 |
| 结构评价 | "与题干论证方式最相似" | 结构对比法：提取逻辑框架 | 问"相似结构" | 40-50秒/题 |

### 翻译推理核心公式（江苏必考）

```
【充分条件】
如果A，那么B  →  A → B
只要A，就B    →  A → B

【必要条件】
只有A，才B    →  B → A
除非A，否则B  →  ¬A → B（等价于 ¬B → A）

【推理规则】
① 肯前必肯后：A→B，A成立 → B成立
② 否后必否前：A→B，¬B成立 → ¬A成立
③ 逆否等价：A→B ≡ ¬B→¬A

【易错点】
✗ 肯后推肯前（错误！）
✗ 否前推否后（错误！）
```

### 论证题核心框架

```
【加强论证】
力度排序（从强到弱）：
1. 搭桥（建立论据与论点联系）★★★★★
2. 补充新论据 ★★★★
3. 排除他因 ★★★
4. 举例支持 ★★

【削弱论证】
力度排序（从强到弱）：
1. 否定论点（直接反驳结论）★★★★★
2. 切断联系（论据与论点无关）★★★★
3. 否定论据 ★★★
4. 另有他因 ★★★

【识别技巧】
① 先找论点（看结论、观点、建议）
② 再找论据（看事实、数据、例子）
③ 分析论证过程（论据如何推出论点）
④ 对比选项力度（江苏卷喜欢考"最能加强/削弱"）
```

### 分析推理专项技巧（江苏高频）

```
【分析推理解题策略】
第一步：整理条件
  - 用符号简化表达（如 张→陈 表示"张则陈"）
  - 标注确定信息（直接给出的事实）

第二步：选择方法
  - 确定信息少（≤2个）→ 代入排除法
  - 确定信息多（≥3个）→ 递推法
  - 复杂条件多 → 假设法

第三步：快速排除
  - 利用确定信息排除明显错误选项
  - 利用矛盾条件排除

第四步：验证答案
  - 将答案代入所有条件验证
  - 确保无遗漏、无矛盾
```

### 高频陷阱

| 陷阱类型 | 表现形式 | 应对策略 |
|---------|---------|---------|
| 翻译错误 | "除非A否则B"翻译成"A→B" | 熟记公式："除非A否则B" = "¬A→B" |
| 推理错误 | 从"A→B"推出"B→A" | 牢记：只能"肯前肯后""否后否前" |
| 论证偷换 | 论点说"销量"，选项说"利润" | 严格对照论点主题 |
| 加强削弱无关 | 选项看似相关，实际话题不一致 | 检查选项是否针对论点 |
| 分析推理条件遗漏 | 只关注明显条件，忽略隐含条件 | 仔细读题，标注所有条件 |
