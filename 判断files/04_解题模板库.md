## 一、定义判断解题模板

### 模板1：单定义判断（用时：40-50秒）

```
【题型识别】题干只有1个定义 + "符合上述定义的是"

【解题流程】
第一步：快速阅读定义（20秒）
  ├─ 圈画关键词：
  │   └─ 主体（谁）：___________
  │   └─ 对象（对谁/什么）：___________
  │   └─ 条件（什么情况/方式）：___________
  │   └─ 结果（达到什么）：___________
  │
第二步：逐项排除选项（20秒）
  ├─ A项：主体符合？对象符合？条件符合？→ 保留/排除
  ├─ B项：主体符合？对象符合？条件符合？→ 保留/排除
  ├─ C项：主体符合？对象符合？条件符合？→ 保留/排除
  └─ D项：主体符合？对象符合？条件符合？→ 保留/排除
  │
第三步：选择完全符合项（5秒）
  └─ 检查：是否有"偷换概念"？
  └─ 确认：完全符合所有关键要素

【输出答案】□
```

**实战示例**（JSS-2021-PD-0076）：
```
题目：社会惰化，指个人在团体中工作不如单独一人工作时努力的倾向。

分析步骤：
1. 圈关键词：
   - 主体：个人
   - 场景：在团体中工作 vs 单独工作
   - 表现：团体中不如单独时努力
   - 本质：倾向性（心理现象）

2. 对比选项：
   A项：讲合作效率（×，不是个人努力程度对比）
   B项：个人在集体中消极（✓，符合"团体中不努力"）
   C项：讲社会分工（×，不是个人努力对比）
   D项：讲评价标准（×，不是努力程度）

3. 答案：B
```

## 二、类比推理解题模板

### 模板3：两词关系（用时：25-30秒）

```
【题型识别】A：B（1个冒号）

【解题流程】
第一步：确定题干关系（10秒）
  └─ A与B的关系类型：___________
      ├─ 逻辑关系（优先）：种属/组成/并列/对应
      ├─ 言语关系：近义/反义
      └─ 关系方向：A→B 还是 B→A
  │
第二步：逐项对比选项（12秒）
  ├─ A项：关系类型相同？方向一致？→ 是/否
  ├─ B项：关系类型相同？方向一致？→ 是/否
  ├─ C项：关系类型相同？方向一致？→ 是/否
  └─ D项：关系类型相同？方向一致？→ 是/否
  │
第三步：选择最优项（3秒）
  └─ 若多项符合，选关系最紧密的

【输出答案】□
```

**关系速查卡**：
```
常见关系快速识别：
- "A用于B" → 功能对应
- "A是为了B" → 目的对应
- "A导致B" → 因果关系
- "A是B的一种" → 种属关系
- "A是B的组成部分" → 组成关系
- "A和B都属于C" → 并列关系
```

## 四、逻辑判断解题模板

### 模板10：翻译推理（用时：50-70秒）

```
【题型识别】题干有"如果...那么""只有...才"等标志词

【解题流程】
第一步：翻译题干（25秒）
  └─ 逐句翻译：
      ├─ 如果A，那么B → A→B
      ├─ 只有A，才B → B→A
      └─ 除非A，否则B → ¬A→B
  │
第二步：整理逻辑链（10秒）
  └─ 合并推理：___________
  │
第三步：对比选项（20秒）
  ├─ 用逆否等价验证：A→B ≡ ¬B→¬A
  ├─ 用肯前肯后：A→B，A成立 → B成立
  └─ 用否后否前：A→B，¬B成立 → ¬A成立
  │
第四步：选择正确推理（5秒）

【输出答案】□
```

**翻译公式速查**：
```
充分条件：
- 如果A，那么B → A→B
- 只要A，就B → A→B
- A是B的充分条件 → A→B

必要条件：
- 只有A，才B → B→A
- 除非A，否则B → ¬A→B（= B→A）
- A是B的必要条件 → B→A

推理规则：
✓ 肯前肯后
✓ 否后否前
✗ 肯后推肯前（错！）
✗ 否前推否后（错！）
```

### 模板12：分析推理（用时：70-120秒）

```
【题型识别】多个条件 + 问排列/组合/匹配

【解题流程】
第一步：整理条件（30秒）
  ├─ 用符号简化表达
  ├─ 标注确定信息
  └─ 标注约束条件
  │
第二步：选择解题策略（5秒）
  │
  ├─【确定信息少（≤2个）】→ 代入排除法
  │   └─ 将选项代入题干验证
  │
  ├─【确定信息多（≥3个）】→ 递推法
  │   └─ 从确定信息出发逐步推理
  │
  └─【条件复杂】→ 假设法
      └─ 假设某选项成立，看是否矛盾
  │
第三步：执行解题（30秒）
  └─ 按所选策略解题
  │
第四步：验证答案（5秒）
  └─ 将答案代入所有条件检查

【输出答案】□
```

**分析推理提速技巧**：
```
1. 优先用确定信息排除
2. 遇到"至少""至多"用反向代入
3. 遇到"不可能"优先假设验证
4. 复杂题目果断跳过，避免超时
```

## 💡 模板使用技巧

### 考前准备
1. **熟读模板**：考前1周每天过一遍所有模板
2. **刷题套用**：做真题时严格按模板步骤执行
3. **个性化调整**：根据个人习惯微调模板细节

### 考场使用
1. **快速识别**：看到题目3秒内判断用哪个模板
2. **严格执行**：按模板步骤走，避免遗漏
3. **时间控制**：严格按模板建议时间，超时果断跳过

### 提速建议
- 定义判断：主体、对象、条件，三要素必查
- 类比推理：逻辑关系优先于言语关系
- 图形推理：先判断立体/平面，再按属性/数量/位置/样式顺序思考
- 逻辑判断：翻译推理记公式，论证题找论点，分析推理用排除

**核心原则**：模板是工具，熟练是关键，速度是目标！
