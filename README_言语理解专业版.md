### 新增字段说明

#### 1. 题型识别
**格式**: 一级分类-二级分类-三级分类
**示例**: `逻辑填空-近义词辨析-单空`

#### 2. 考察内容
包含:
- 考察的知识点和能力
- 核心能力要求
- 江苏特色/陷阱
- 300字专业描述

#### 3. 思维方式
**格式**: 5-7步详细解题流程
**示例**: ①阅读题干,找语境提示→②拆词法分析侧重→③代入验证→④排除错误项→⑤选择最优答案

#### 4. 解题方法
**结构化呈现**:
- 【核心技巧】: 最重要的方法
- 【方法】: 具体步骤
- 【江苏特色】: 特殊规律
- 【辅助】: 辅助方法

## 🎯 江苏省考言语理解5大特色

### 1. 逻辑填空占比最高 (59.3%)
- **特点**: 近义词辨析为主,成语辨析为辅
- **核心方法**: 拆词法 + 语境对应法
- **备考重点**: 词汇积累 + 词义侧重辨析

### 2. 侧重词义辨析
- **高频考法**: 改善vs改进、提高vs增强、推动vs促进
- **核心方法**: 拆词法分析侧重点
- **关键**: 结合语境选择最契合的词

### 3. 主旨概括重关联词
- **五个不重要**: 背景铺垫/举例论证/原因解释/援引观点/反面论证
- **五个关系**: 递进/并列/转折/因果/总分
- **核心规律**: 转折后、结论句、递进后是重点

### 4. 细节判断重陷阱
- **六大陷阱**: 时间/数量/概念/范围/逻辑/程度
- **核心方法**: 回文定位 + 逐字比对
- **重要规律**: 绝对化往往错误,可能性往往正确

### 5. 语句排序重首句
- **核心方法**: 排除首句法
- **首句特征**: 不含指代词、不含承接词(也/同样/同时)
- **辅助方法**: 关联词法 + 指代词法

## 📖 使用方法

### 刷题阶段
1. 打开JSON文件,对照三级分类针对性练习薄弱题型
2. 每道题都参考"思维方式",形成标准解题流程
3. 重点关注"考察内容"中的江苏特色和陷阱

### 考前冲刺
1. 熟记"解题方法"中的核心技巧
2. 重点复习江苏5大特色
3. 练习做题顺序:逻辑填空→主旨概括→细节判断→语句表达

### 查漏补缺
1. 按三级分类统计错题分布
2. 针对高频错误题型,重点研究"考察内容"
3. 对比标准"思维方式"与自己的解题思路

## 💡 备考建议

### 重点突破 (占比>50%)
1. **逻辑填空-近义词辨析**: 拆词法 + 语境对应法
   - 时间分配: 30秒/题
   - 训练目标: 快速识别词义侧重点

2. **片段阅读-主旨概括**: 关联词法 + 主题词法
   - 时间分配: 45秒/题
   - 训练目标: 快速定位主旨句

### 次重点 (占比20%-50%)
3. **片段阅读-细节判断**: 六大陷阱识别
   - 时间分配: 40秒/题
   - 训练目标: 精准比对,避免陷阱

### 一般重点 (占比<20%)
4. **语句表达-语句排序**: 排除首句法
   - 时间分配: 1分钟/题
   - 训练目标: 快速排除,验证逻辑

5. **语句表达-下文推断**: 尾句话题延续
   - 时间分配: 45秒/题
   - 训练目标: 把握话题延续
